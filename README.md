## 🧠 About The Project

NOVA is a sleek, dark-themed portfolio designed to:

* Attract clients
* Showcase creative work
* Convert visitors into leads

It combines **modern UI design, animations, and clean structure** to deliver a premium experience.

---

## ✨ Features

* 🎬 Animated hero section (typewriter effect)
* ⚡ Smooth scroll animations (AOS)
* 🎨 Glassmorphism UI design
* 🖼️ Project gallery with modal preview
* 🌗 Dark / Light mode toggle
* 📱 Fully responsive design
* 📞 WhatsApp direct contact integration

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)
* AOS (Animate On Scroll Library)

## 🚀 Getting Started

To run this project locally:

1. Clone the repository

```
git clone https://github.com/yourusername/nova-portfolio.git
```

2. Open the folder
3. Run `index.html` in your browser

## 🌍 Deployment

This project is deployed using **GitHub Pages**.

To deploy:

* Go to repository **Settings**
* Click **Pages**
* Select branch: `main`
* Save
